
# Simple Airline Management System (SAMS) - CS 4400 Phase 4

## Setup Instructions

1. Install dependencies:
   pip install -r requirements.txt

2. Start your MySQL server locally.

3. Import the provided `cs4400_sams_phase3_mechanics_TEMPLATE_v0.sql` file into your MySQL server.

4. Run the backend server:
   python backend/app.py

5. Open your browser and go to:
   http://localhost:5000

6. Navigate to:
   - Flights
   - Customers
   - Airlines
   - Airports
   - Employees
   - Reservations
   for full CRUD functionality.

## Technologies Used
- Python Flask (Backend)
- MySQL (Database)
- HTML + Bootstrap (Frontend)
